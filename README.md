# Kashmir Got Talent

The initial frontend for the official Kashmir Got Talent website. Built with
React, Vite, React Router DOM, and Lucide React. This project has no backend or
admin dashboard.

## Run locally

```bash
npm install
npm run dev
```

## Project structure

- `src/components/` — reusable navigation, footer, buttons, and page shell
- `src/pages/` — one routed component and stylesheet per proposed page
- `src/data/` — route and navigation metadata
- `src/assets/` — brand assets
- `src/styles/` — global reset, design tokens, and shared page styles
- `src/utils/` — small shared application utilities

The pages are intentionally structural at this stage; no unverified event,
participant, sponsor, testimonial, or policy details are supplied.
